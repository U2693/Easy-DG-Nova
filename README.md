# Easy Programs for the DG Nova

One easy program for the Data General Nova, every week.

**Read the blog:** https://u2693.github.io/easy-dg-nova/

Season 1 runs 24 episodes — one new small program a week, in Nova
assembly or BASIC, each one teaching a single idea and verified on
the machine before it is published. Written collaboratively by
Randall Bohn (U2693) with Eli.

The page in this repository (`index.html`) is the blog's front
page: the premise, the rules of what "easy" means here, a preview
of Episode 01, and the full Season 1 lineup. It is generated from
the project's working Space and updated as episodes land.
